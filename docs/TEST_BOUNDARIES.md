# Tests that protect B1's meaning

These are implementation acceptance targets, not tests already implemented here.

| Test | Failure it should catch |
|---|---|
| Oracle perturbation | Hidden truth changes while visible evidence is unchanged; controller input must not change |
| Allowed-view serialization | Unexpected fields, privileged metadata, or environment objects enter the controller input |
| Unselected branch isolation | A controller can read another action's cached output |
| Forbidden evaluator access | Real controller process can access evaluator files, credentials, or unrestricted network tools |
| Grouped split integrity | Same base world/near-duplicate renderings cross train and held-out groups |
| Metadata leakage | Family names, paths, scenario IDs, or order encode outcomes unintentionally |
| Identity mismatch | Provider/model/config changes without a new arm/version or explicit failure |
| Sample/cache semantics | Repeated independent calls collapse into one cached response |
| Resume equivalence | Interrupted/resumed aggregation duplicates, drops, or changes accepted records |
| Failure accounting | Timeout, parse failure, refusal, or retry disappears from denominators/cost |
| Decision lock | Oracle feedback changes the stored pre-audit decision |
| Full-inspection parity | Comparator is denied information that the new method receives |
| Fresh-clone report | Report needs undeclared local files, credentials, or live model calls |

Development agents may access development labels for engineering. Final holdout
labels, instances, and response banks must live outside their account/mounts. A Git
branch, worktree, directory named private, .gitignore rule, or AGENTS.md instruction
is not an access-control mechanism. Restrict actual users, mounts, credentials, and
service interfaces. Use separate agent profiles/homes for sealed evaluation; review
whether shared tool memory could carry test content back to development.

If there is only one researcher, a separate evaluation account/container and a
recorded freeze still reduce accidental exposure, but do not claim fully independent
blind evaluation. Every tuning response to a final result changes its interpretation.
