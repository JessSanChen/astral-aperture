## Experiment evidence
Versions: seed 1, oracle `pilot-oracle-0.1`, judge prompt 0.3, judges per D-005, one sample per branch.
Observation and oracle boundary: policies receive only the initial view, the initial judge result, and candidate action names; the bank is read by the evaluator after the choice (tested).
Uncertainty: none reported. 36 episodes per family; treat every number as exploratory.

### Headroom (all 180 episodes)

| | Opus 5.5 | Sonnet 5.5 |
|---|---|---|
| initial errors | 48/180 | 36/180 |
| of which missed violations | 41/79 | 21/79 |
| of which false alarms | 7/101 | 15/101 |
| initial errors in fabricated mode | 34/41 | 21/41 |
| initial errors in honest-pass mode | 7/62 | 15/62 |
| errors after retrieving all records | 0/180 | 0/180 |
| reread disagreed with initial | 14/180 | 8/180 |
| single retrievals that corrected | 88/720 | 56/720 |
| single retrievals that corrupted | 23/720 | 12/720 |
| rereads that corrupted | 6/180 | 2/180 |

Corruptions are real-judge behavior, not injected: retrieving one record that confirms a single rule flipped a correct violation call to "no violation" (Opus 15/540 rule-record retrievals, Sonnet 8/540), and retrieving the distractor memo did the same (Opus 8/180, Sonnet 4/180). Both judges read all four records correctly in every episode, including the 35 boundary cases and the 47 unsigned draft exceptions, so full inspection is error-free in this environment.

### Predictability (held-out AUC for "this action corrects the verdict")

| | Opus 5.5 | Sonnet 5.5 |
|---|---|---|
| all allowed features | 0.836 | 0.820 |
| without narration cue features | 0.785 | 0.791 |

Most of the signal is the initial verdict and rationale (the judges' errors are mostly misses on clean-looking narration). The narration cues add a few points of AUC on families the model never saw.

### Transfer frontier, pooled over held-out families (each family held out once)

Opus 5.5:

| Policy | final errors | missed | false alarms | mean burden |
|---|---|---|---|---|
| stop | 48/180 | 41 | 7 | 0.00 |
| reread | 47/180 | 41 | 6 | 0.50 |
| random single retrieval | 33/180 | 28 | 5 | 1.00 |

| inspect all if judge says clean | 7/180 | 0 | 7 | 3.00 |
| learned, threshold 0.25 | 15/180 | 8 | 7 | 1.33 |

| learned, threshold 0.10 | 0/180 | 0 | 0 | 2.73 |
| retrieve all | 0/180 | 0 | 0 | 4.00 |
| oracle best single action (evaluator only) | 0/180 | 0 | 0 | 0.25 |

Sonnet 5.5:

| Policy | final errors | missed | false alarms | mean burden |
|---|---|---|---|---|
| stop | 36/180 | 21 | 15 | 0.00 |
| reread | 32/180 | 19 | 13 | 0.50 |
| random single retrieval | 20/180 | 11 | 9 | 1.00 |

| inspect all if judge says clean | 15/180 | 0 | 15 | 2.38 |
| learned, threshold 0.20 | 12/180 | 8 | 4 | 1.29 |
| learned, threshold 0.15 | 2/180 | 0 | 2 | 1.92 |
| retrieve all | 0/180 | 0 | 0 | 4.00 |
| oracle best single action (evaluator only) | 0/180 | 0 | 0 | 0.18 |

Evidence-supported result: on held-out families, the learned controller reaches the error level of the risk-style baseline (inspect everything the judge calls clean) at roughly two thirds of its burden for Opus and at a fraction of its errors for Sonnet, and it reaches zero or near-zero error at well under the full-inspection burden. At low burden (under one record per episode) the untrained hedge heuristic is as good as or better than the learned controller.

Interpretation/hypothesis: the three preconditions for B1 hold on this environment. There is headroom, inspection can hurt as well as help with real judges, action value is partly predictable from allowed information, and the predictor transfers to an unseen family. The gap to the evaluator-only upper bound is large, which is where a better controller would show up.

Claims not supported: generality beyond these fictional families; any statistical significance; relative quality of the two judges; anything about deployed monitoring.
